# CUYRA Catalog Cloud V4.3.0 · MOBILECOMMERCE01

Correctivo/evolución visual acumulativa sobre **V4.2.0 GALLERY01**.

## Objetivo
Llevar la experiencia móvil del catálogo a una navegación más cercana a una web-app comercial, tomando como referencia la jerarquía UX aprobada por el usuario, sin copiar branding de otro tenant y sin reestructurar la base de datos.

## Qué cambia
- Home móvil más compacta y orientada a exploración.
- Header móvil con marca del tenant, favoritos, pedido y menú.
- Accesos rápidos y rail horizontal de categorías.
- Navegación inferior fija.
- Catálogo móvil de dos columnas con quick-add.
- Buscador y toolbar compactos.
- Filtros en bottom sheet con footer fijo.
- Rango de precio (`minPrice` / `maxPrice`).
- Filtro de destacados (`featured=1`) usando el campo ya existente.
- Botón de filtros muestra cantidad de filtros activos.
- `Ver N productos` cierra el sheet sin perder selección.

## Qué NO cambia
- No hay migración SQL nueva.
- No se renombra ni recrea ningún tenant.
- No se modifica el contrato de sincronización CUYRA.
- No se cambia el modelo de variantes o galería.
- No se implementa checkout/pago web.
- No se inventan descuentos: `Destacados` usa el campo `featured` existente.
- Desktop y PDP continúan sobre la lógica acumulativa previa.

## Deploy recomendado
1. Crear rama/Preview desde el deployment estable actual.
2. Reemplazar con este FULL SOURCE.
3. No ejecutar migraciones nuevas por este bloque.
4. Confirmar `/api/health` = `4.3.0`.
5. Probar un tenant real en móvil: Home → Categorías → Buscar → Filtros → quick-add → Pedido.
6. Probar desktop y PDP para confirmar ausencia de regresiones.
7. Publicar a producción solo después del Preview.
