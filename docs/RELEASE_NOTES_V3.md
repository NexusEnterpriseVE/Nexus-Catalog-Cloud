# Release Notes — Nexus Catalog Cloud V3

V3 transforma el catálogo público básico en una vitrina comercial completa.

## Nuevo
- navegación de tienda;
- filtros por marca/categoría/subcategoría;
- ordenamiento;
- ficha individual de producto;
- productos relacionados;
- marca/modelo/características;
- destacados;
- branding del tenant;
- logo empresarial sincronizable;
- estilos Retail / Minimal / Bold;
- responsive móvil/tablet/escritorio.

## Compatibilidad
La migración de Supabase es aditiva. No elimina tenants ni productos existentes.
